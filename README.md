# Velora

A modern fashion ecommerce website designed around a clean, premium shopping experience.

## ✦ About

Velora is a responsive fashion ecommerce project featuring a product-focused shopping experience with categories, search, sorting, wishlist interactions, quick product views, and a shopping bag.

## 🛠️ Technologies

### Frontend

* React 18
* JavaScript
* CSS3
* Tailwind CSS

### Backend

* Node.js
* Express.js
* REST API
* JSON-based product storage

## ✨ Features

* Fashion ecommerce interface
* Product catalog with 24 products
* Category filtering
* Product search
* Product sorting
* New arrivals
* Sale products
* Product ratings and reviews
* Wishlist functionality
* Quick View modal
* Shopping bag/cart
* Quantity controls
* Responsive design
* Mobile navigation
* REST API for products

## ⚙️ Architecture

The frontend is built with React and communicates with a Node.js + Express backend through REST API endpoints.

Product data is stored locally in JSON and served through the Express API.

## 🚀 Getting Started

### Frontend

```bash
npm install
npm start
```

### Backend

```bash
cd backend
npm install
node server.js
```

The backend runs on:

```text
http://localhost:5000
```

The products API is available at:

```text
http://localhost:5000/api/products
```
